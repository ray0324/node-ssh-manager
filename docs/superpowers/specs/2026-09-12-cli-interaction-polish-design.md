# sshm CLI 交互优化设计

## 目标

在不增加搜索、排序、分组或详情面板等新功能的前提下，统一现有 sshm TUI 的视觉语言、键盘操作和异步反馈。界面以简体中文为主，并保证在标准 80 列终端中清晰可用。

## 非目标

- 不改变 vault、主机数据结构或 SSH 连接流程。
- 不新增第三方依赖。
- 不增加鼠标操作、主题系统、搜索、排序或分组。
- 不针对低于 80 列的终端做专门布局。

## 界面结构

### 主机列表

- 顶栏显示 `sshm · SSH 主机管理器`，右侧显示主机数量。
- 主列表继续显示别名和 `用户@主机:端口`。
- 当前项使用 `›`、青色和反色共同突出，避免只依赖颜色表达选择状态。
- 空列表显示明确的中文引导，提示按 `a` 添加主机。
- 底栏把按键和说明分开呈现，并区分主要操作与次要操作。
- 弹层打开时，底栏仅显示当前弹层可用的操作。

### 新增与编辑表单

- 字段统一命名为“别名、主机、端口、用户、密码、备注”。
- 必填字段显示 `*`，焦点字段以青色和指示符突出。
- `Tab` 和 `Shift+Tab` 在字段间循环，Enter 前往下一项，备注字段按 Enter 保存。
- 保留 `Ctrl+S` 保存、`Ctrl+R` 显示或隐藏密码、Esc 取消。
- 底部提示与实际支持的按键严格一致。

### 初始化与解锁

- 文案统一为简体中文，并明确主密码不可找回。
- 提交期间显示忙碌状态并阻止重复提交。
- 提交失败后保留仍然有效的输入；密码错误时清空密码，便于立即重试。

## 操作与状态

### 列表操作

列表保留以下快捷键：

- `↑` / `↓` 或 `k` / `j`：移动选择。
- Enter：连接当前主机。
- `a`：添加主机。
- `e`：编辑当前主机。
- `d`：删除当前主机。
- `p`：查看当前主机密码。
- `q`：退出。

不存在当前主机时，与主机相关的操作不执行。列表变化后将游标钳制到有效范围。

### 删除确认

- 默认聚焦“取消”，降低误删风险。
- 方向键、`h` / `l` 或 Tab 切换按钮，Enter 执行，Esc 取消。
- 删除期间锁定输入并显示“正在删除…”，防止重复调用。
- 删除失败时保留确认界面并显示中文错误；成功后关闭弹层并修正列表游标。

### 密码查看

- 使用独立的敏感信息面板显示主机别名和密码。
- 面板明确提示按任意键或 Esc 关闭。
- 用于关闭面板的按键不会继续触发底层列表操作。

### 表单保存与校验

- 保存时锁定输入并显示“正在保存…”，防止重复提交。
- 本地检查端口范围及所有必填字段。
- 首个错误使用中文说明，并将焦点移动到对应字段。
- 用户修改错误字段后清除旧错误。
- 仓库层错误映射为可理解的中文提示，例如别名重复；无法识别的错误保留安全的通用说明。
- 保存成功后返回列表并刷新，失败时保留表单内容。

## 组件职责

- `App`：保留现有路由和仓库调用职责，成功后切换页面并刷新列表。
- `ListScreen`：管理游标、密码面板、删除流程及当前状态下的快捷键。
- `HostList`：只呈现主机行和空状态。
- `Footer`：接收结构化按键项，负责按键和说明的统一样式及分组。
- `ConfirmModal`：管理按钮焦点、确认、取消、忙碌状态与删除错误。
- `HostFormScreen`：管理字段焦点、输入值、本地校验、错误和保存状态。
- `InitScreen` / `UnlockScreen`：管理主密码输入、提交状态和错误反馈。

组件之间继续通过现有 props 回调通信，不引入全局 UI 状态。

## 数据流与错误处理

新增、编辑和删除沿用 `Screen → App → HostRepo → Vault` 的调用链。Screen 在等待 Promise 时进入忙碌状态；成功后由 App 刷新或切换路由；失败后 Screen 保持当前上下文并显示错误。

UI 层只负责把已知校验和仓库错误转换为中文。底层 schema 和异常行为保持不变，避免交互优化改变存储语义。

## 测试

使用 `ink-testing-library` 和 Vitest 覆盖：

- 列表上下移动、快捷键回调和空状态。
- 弹层打开后的输入隔离。
- 删除确认的默认焦点、取消、提交锁定、成功和失败。
- 密码面板显示与关闭。
- 表单正反向导航、Enter 行为、必填项与端口校验、保存锁定和失败保留。
- 初始化与解锁的校验、忙碌状态和失败反馈。
- Footer 的结构化按键呈现。

验收时运行完整 Vitest 测试和 TypeScript 构建。界面应在 80 列终端中无明显提示拥挤或关键信息截断。
