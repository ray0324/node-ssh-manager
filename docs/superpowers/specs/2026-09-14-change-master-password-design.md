# sshm 更改主密码设计

## 目标

在已解锁的主机列表中提供更改主密码能力。用户必须再次验证当前主密码，然后设置新密码。成功后用新 salt 与新密钥原子重写 vault，会话继续可用。

## 非目标

- 不提供忘记主密码后的恢复或重置。
- 不增加命令行子命令（例如 `sshm passwd`）。
- 不增加设置页、备份副本或多端同步。
- 不改变 vault 文件格式、主机数据模型或 SSH 连接流程。
- 不新增第三方依赖。

## 入口与界面

- 仅从主机列表进入：按 `c` 打开改密界面。
- `c` 放在底栏次要操作组，与 `d`、`p`、`q` 并列，文案为“更改主密码”。
- 弹层打开时 `c` 不生效，行为与现有列表快捷键一致。

改密界面字段：

1. 当前主密码
2. 新主密码
3. 再次输入

交互：

- `Tab` / `Shift+Tab` 循环字段，Enter 前往下一项，最后一项 Enter 或 `Ctrl+S` 提交。
- Esc 取消并返回列表，不写盘。
- 密码默认掩码；沿用表单的 `Ctrl+R` 显示或隐藏。
- 提交期间锁定输入并显示“正在更改主密码…”。
- 成功后返回列表，并显示成功提示“主密码已更改”；下一次列表按键后清除。
- 全部用户可见文案使用简体中文。

## 校验与错误

本地校验（不写盘）：

- 当前主密码不能为空。
- 新主密码至少 4 个字符，规则与初始化相同。
- 两次新密码必须一致。
- 新主密码不能与当前主密码相同。

首个错误用中文说明，并聚焦对应字段。用户修改该字段后清除旧错误。

仓库/Vault 错误：

- 当前主密码不正确：清空当前主密码字段，聚焦该字段，提示“当前主密码错误，请重试”。不改 vault 文件。
- 写盘失败：保留输入，提示“更改主密码失败，请重试”。内存密钥与磁盘文件仍为旧密码。
- 无法识别的错误使用通用说明“更改主密码失败，请重试”。

## Vault 行为

现有 `create`、`unlock`、`save` 保持不变。新增：

```ts
changePassword(current: string, next: string): Promise<void>
```

步骤：

1. 用文件中的现有 salt 对 `current` 做 scrypt 派生。
2. 与内存中的密钥做恒定时间比较；不匹配则抛出可识别错误。
3. 生成新的 16 字节 salt，用 `next` 派生新密钥。
4. 用新密钥和新 salt 加密当前 `data`，经现有临时文件 + `fsync` + rename 原子替换 `vault.enc`。
5. 仅在写盘成功后替换内存中的 `key` 与 `salt`。

写盘失败时不更新内存密钥。成功后后续 `save()` 只使用新密钥。不改变 MAGIC、VERSION 或明文 JSON schema。

## 组件职责

- `App`：增加 `{ kind: 'change-password' }` 路由；调用 `vault.changePassword`；成功后回到列表并带上成功提示。
- `ListScreen`：处理 `c`；接收并展示来自改密成功的短暂状态提示。
- `ChangePasswordScreen`：管理字段焦点、掩码、本地校验、忙碌状态和错误。
- `Vault`：验证当前密码并原子重写加密文件。
- `Footer`：列表次要组增加 `c` 提示，无需改组件接口。

组件继续通过 props 回调通信，不引入全局 UI 状态。`HostRepo` 与 SSH 客户端不参与改密。

## 数据流

```
ListScreen --c--> App --route--> ChangePasswordScreen
ChangePasswordScreen --onSave(current, next)--> App --> Vault.changePassword
成功：App 回到 list，并传入成功提示
失败：停留在 ChangePasswordScreen
Esc：App 回到 list，不调用 Vault
```

密钥只存在于 `Vault` 实例内部。Screen 不持有派生密钥。

## 测试

Vault：

- 错误的当前密码不修改文件，且仍可用旧密码解锁。
- 成功后旧密码无法解锁，新密码可以解锁，数据不变。
- 新密码与当前密码相同被拒绝。
- 模拟写盘失败时文件与内存密钥仍对应旧密码。

界面：

- 列表按 `c` 进入改密（由 App 或 ListScreen 测试覆盖）。
- 必填、长度、两次不一致、新旧相同的中文校验。
- 当前密码错误时清空该字段并保留新密码输入。
- 提交锁定，Esc 取消不调用 `onSave`。

验收运行完整 Vitest 与 TypeScript 构建。
